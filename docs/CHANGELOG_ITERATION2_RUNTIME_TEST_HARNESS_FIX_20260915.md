## 失败归因与测试修正

- 将功性魔防壁II、III、IV从重构前的16/32/200伤害断言，改为当前DesignDoc的3/5/50层荆棘，并验证II、III各生成下一阶段。
- 将心眼伤害更新为3，将闪电反冲伤害更新为5/8；将瘴气转化的旧“力量”断言改为每消耗1张牌获得1层魔力增幅。
- 倒刺钩、衣物燃烧、咬衣纸片、溶解液及腐蚀黏液测试会先实际进入无垢天衣形态，再验证逐次减少1层魔装耐久，不再构造“普通形态却强行挂有耐久Power”的非法状态。
- 暴露狂、露出play、诱敌深入和淫乐园改为验证诱惑度增量，避免把角色固有10点基础诱惑度误判为卡牌额外效果。
- 祝圣改为调用其真实的`AfterPlayerTurnStart`钩子；记忆的刻印改为调用其真实的`BeforeHandDraw`钩子。
- 精神统一预览测试先将卡牌放入战斗手牌并使用玩家作为格挡目标，再运行全局Hook，避免脱离牌堆的测试卡触发空战斗状态。
- 黑暗元素及暗焰壁障在已有魔力增幅时按1.5倍后的实际伤害/格挡断言，同时继续验证魔力解放分支。
- 纯净宝珠和风神披风的升级费用改用当前基础费用而非永远保存构造费用的`EnergyCost.Canonical`。
- 反射屏障改为验证每次消耗恰好增加1层魔力增幅，避免升级牌打出时自身消耗与随后主动消耗第二张牌的累计值被误判。
- 退魔香水与圣焰的最低效果断言数量改为各自实际存在的2项和3项；两者的数值断言没有删减。
- 淫乐园只要求非意志坚定且存在色情意图配置的合法敌人被替换，并要求测试遭遇至少含一个合法目标。
- 每个测试场景重置怪物时，同时丢弃该怪物旧的色情意图运行状态，防止基础场景的次数和冷却污染升级场景。
