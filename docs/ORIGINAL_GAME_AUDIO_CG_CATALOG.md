# 《魔法少女天穹法妮雅》音频与CG素材盘点

> 盘点日期：2026-09-25  
> 原作目录：`D:\game_backup\butter\魔法少女天穹法妮雅 超魔改 V56.5 魔改三合一1`  
> 用途：评估原作素材在“响木天音”STS2 Mod游戏流程中的设计适配性。本文不改变DesignDoc需求，也不代表已经取得素材再发布授权。

## 一、结论摘要

原作资源在技术上已经具备较高复用价值：音频目录中存在可直接读取的OGG文件，事件CG也已是PNG，而非只有RPG Maker加密副本。最值得优先接入的不是整套成人场景，而是下列小规模、能够强化角色身份的素材：

1. 角色选择或角色介绍使用1首原作主题/魔法场景BGM。
2. 女神试炼、第四层Boss和路线结局各使用1首有明确原作用途的BGM。
3. 魔装破损、变身、欲望阈值、试炼推进使用一组短音效或过场音。
4. “按摩店”事件、榨乳器事件/遗物、怪物战败过场分别选择少量关键CG，而不是导入整组差分。
5. `actor01_pose*`、服装、表情与淫纹图层适合角色立绘系统；`Eve_*`更适合一次性事件或结局过场，不适合常驻战斗UI。

原作的音乐文件名显示，其中相当一部分来自第三方素材包或素材作者。**能够从已购游戏中读取文件，不等于拥有将它们随Mod重新分发的权利。** 在公开发布前必须逐项确认原作者授权范围；授权不明确的音频和CG只能用于本地原型验证，正式版应取得许可或换用重新创作的替代素材。

## 四、CG全量分组索引

### 4.1 评级口径

- **A：直接匹配**——现有Mod流程已有对应事件、机制或结局，只需选择具体差分并适配UI。
- **B：可转用**——主题相符，但需要新增叙事、裁切或严格筛选帧。
- **C：暂不使用**——与当前爬塔流程缺少联系、主体不是天音，或整组过于庞杂。

评级只表示设计适配性，不代表授权状态和内容尺度审核结果。

## 六、接入时的技术约束

1. **不使用`.rpgmvo`。** 当前已有对应OGG，复制加密副本只会增加体积并引入无意义的解密流程。
2. **重命名资源。** 将最终选中的文件改为稳定的Mod资源ID，例如`hibiki_trial_intro.ogg`、`hibiki_armor_break.ogg`，不要在代码中依赖带空格和大小写混杂的原始文件名。
3. **检查循环标签。** RPG Maker音乐可能依赖Vorbis的`LOOPSTART/LOOPLENGTH`标签；Godot导入后必须实际测试循环是否无缝。
4. **统一响度。** 原作素材来自不同素材包，响度差异可能很大。应在复制进Mod前完成响度标准化，避免盖过STS2原声或音效。
5. **CG必须裁切。** `Eve_*`全部为1024×768，包含原作紫色回想边框。STS2直接显示会形成框中框；应保留原始文件不动，在Mod素材目录中生成裁切副本。
6. **控制包体。** 974张完整CG超过1 GB，全部随Mod分发不可接受。建议首轮不超过15张CG，压缩后控制在20～40 MB。
7. **不在运行时组合全部差分。** 服装、表情和淫纹图层应在制作阶段合成最终PNG；运行时只切换少量确定状态。
8. **为R18画面设置独立开关。** 普通事件文本、战斗与卡牌不应突然弹出高尺度CG；关闭时以文字、遗物图标或含蓄裁切替代。
9. **不覆盖STS2全局音乐。** 角色Mod优先在专属事件、专属Boss和结局中播放原作音乐；普通楼层、战斗、商店和火堆继续沿用STS2按幕配置的音乐。

## 七、发布前权利核对

正式打包任何原作素材前，至少确认以下事项：

- 原作开发者/发行者是否允许在其他游戏的免费Mod中再发布CG与角色图。
- 每首第三方音乐、音效素材的许可是否允许“嵌入另一游戏并随Mod分发”，而不仅是允许原作开发者商用。
- 是否需要在Mod页面和游戏内追加素材作者、曲名与许可来源。
- “超魔改”新增的`Eve_60/61`等素材是否来自原作官方、魔改作者或其他来源；来源不明时不得进入公开发布包。
- 若无法取得明确许可，只保留文件名与用途映射，用原创重绘、重新编曲或可商用替代素材实现同一设计功能。
