## 2. 变身、魔装、欲望与透支

- [ ] 每场战斗从普通形态、0耐久开始；变身后耐久重置为3且不会超过3。
- [ ] 耐久3/2/1分别显示无损/破损/严重破损服装；解除变身恢复校服。
- [ ] 待机、攻击、技能、受击、死亡五种视觉反馈均可辨认；素材缺失时不阻塞战斗。
- [ ] 每回合第一次敌方未格挡攻击：生命损失减半且耐久-1；同回合后续段数/攻击不再触发。完全格挡、主动失血、无阻挡伤害不消耗耐久。
- [ ] 耐久归零立即解除变身；普通形态不能获得耐久。
- [ ] 变身状态每个玩家回合获得1层魔力增幅；每张攻击/技能最多消耗1层，同牌全部伤害和格挡提高50%，含多段与延迟效果。
- [ ] 有魔力增幅时透支强制消耗增幅；无增幅且有耐久时始终出现“透支/不透支”两个说明明确的选项；无可支付资源时不触发透支。
- [ ] 欲望跨战斗、跨保存读取；达到10后的禁牌时序正确；8点及以上欲望按文档绕过拘束格挡。
- [ ] 左侧竖向欲望条在地图、房间与战斗中始终显示；进入战斗后不隐藏，并与费用旁的RitsuLib欲望计数器同时显示、数值同步。

## 3. 拘束、挣脱、侵犯与怪物意图

- [ ] 分别用`ms_control_intent attack|skill|power`测试三种拘束：敌人执行意图时不得卡死或闪退；对应牌投影为挣脱，随身牌不变化。
- [ ] 悬停挣脱牌时可查看保留升级/附魔/苦难的原牌预览及带来源的拘束Power；挣脱卡面只显示挣脱文本和锁链覆盖层。
- [ ] 拘束期间保存退出再进入：投影仍绑定同一来源；解除后同一卡实例恢复原标题、关键字、升级、附魔和苦难。
- [ ] 多个拘束同时存在时优先最低剩余挣脱值，同值按敌人从左到右；溢出挣脱值不转移。
- [ ] 挣脱后弱怪晕眩、强怪进入表中恢复意图；意志坚定怪物不产生色情意图。
- [ ] `ms_invasion_intent`成功后永久加入指定精液诅咒并晕眩；商店清理一次移除全部精液类诅咒，每张返还50金币且不影响普通删牌。
- [ ] 耐久3/2/1时自然替换率体感分别约10%/30%/50%；多敌人独立判定，A→B→I优先级、3:1首选权重和逐类型次数上限有效。
- [ ] 固定种子重开时意图序列可重放；战斗保存读取后次数、拘束来源和恢复意图不丢失。
- [ ] “诱敌深入”点选无拘束意图敌人时不耗牌，并显示“这名敌人没有拘束意图。”
