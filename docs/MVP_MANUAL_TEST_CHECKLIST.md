# Maiden & Succubus 单人MVP统一手测清单

> 对应Plan：M9；对应DesignDoc基线：`d067a56`加2026-08-16工作区变更。
>
> 新增了Card/Relic Model与Harmony补丁，必须完整退出并重启游戏；热加载不足以证明注册成功。

## A. 启动、隔离与百科

- [ ] 完整重启后Mod加载，无致命错误、裸本地化键或持续异常日志。
- [ ] 使用原版角色进入Run：不显示堕落条/欲望条，三个事件保持原版选项，卡牌奖励不出现本Mod卡。
- [ ] 使用本Mod普通/圣女/魅魔开局：堕落初值分别为0/-3/+3，UI位置正确。
- [ ] 百科可见三路线MVP卡、六张圣言和新遗物；`未定名·圣洁防御01`不显示裸键。

## B. 既有核心闭环回归

- [ ] 欲望跨战斗、保存/读取后保持；10点结算为3并获得一回合无法出牌。
- [ ] 欲望不足时不能打出有欲望费用的牌；融汇生成的牌本回合能量与欲望费用均为0。
- [ ] 堕落±3封印仅在下一场战斗更新；火堆可免费批量移除封印牌且不占行动。
- [ ] 第一张进入手牌的随身牌回合末保留；离手后名额释放；第二张随身牌正常弃掉。
- [ ] 保存并退出战斗后继续游戏，不黑屏，手牌/牌堆/临时状态可恢复。

## C. 本次卡牌变更

- [ ] 力量的代价：未升级/升级均获得4力量；分别在3/4回合后的回合结束受到30点伤害。
- [ ] 未定名·圣洁防御01：0费，获得2/3临时敏捷，原生保留，敏捷在本回合结束清除。
- [ ] 瞬时恩典：1费，获得6/8格挡与固定2临时敏捷，敏捷在本回合结束清除。
- [ ] 终末审判：1费攻击，先给目标1断罪再审判；低于7层也会审判；其他敌人受到相同数值伤害。
- [ ] 终末审判面对仅一个敌人、多个敌人、目标已有6层断罪和“万劫不复”时均无重复审判或崩溃。

## D. 遗物

- [ ] 双向棱镜：任意堕落值均使圣洁/堕落出现率各+20个百分点；-1至1可重掷卡牌奖励。
- [ ] 双向棱镜：堕落值≥2时堕落率再+20个百分点；≤-2时圣洁率再+20个百分点。
- [ ] 眼罩：敌人意图始终不可见，但意图正常执行；移除/不持有该遗物时意图正常显示。
- [ ] 跳蛋：同一玩家回合第一次未格挡伤害+1欲望，后续不触发；下一玩家回合恢复；全格挡伤害不触发。

## E. 原版事件扩展

- [ ] 光与暗的门扉：暗门移除1牌并+1堕落；光门随机升级2牌并-1堕落。
- [ ] 混沌芳香：放任自流变化1牌、+1堕落、+1欲望；维持理智升级1牌、-1堕落、-1欲望（最低保持0）。
- [ ] 低语空谷：拥抱树木除原版效果外+1堕落。
- [ ] 低语空谷：堕落≤-2解锁净化，获得300金币并加入腐朽；否则显示锁定项。
- [ ] 低语空谷：堕落≥4解锁吸收灵魂并获得枯树灵魂；否则显示锁定项。
- [ ] 用原版角色分别进入上述事件，确认没有额外资源结算和新增选项。
