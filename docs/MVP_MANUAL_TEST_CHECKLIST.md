# Maiden & Succubus MVP统一手测清单

> 对应`DOC-MVP-001`与MVP-0～MVP-5。代码完成记为`IMPLEMENTED`；全部运行时项目通过后才记为`VERIFIED`。
>
> 本轮新增大量Model、注册特性、存档字段和Harmony补丁，必须完整退出并重启游戏。热加载只用于之后的方法体/数值调整。

## 0. 测试记录

- [ ] 记录游戏版本、RitsuLib版本、Mod提交、种子、语言和进阶等级。
- [ ] 启动日志出现`Framework self-tests passed`与`Maiden & Succubus ready`，无Harmony失败和裸本地化键。
- [ ] 遇到失败时记录最短复现步骤、日志、截图及`ms_dump`输出。

## 1. 启动、角色隔离与开局

- [ ] 原版角色：不显示堕落条/欲望条；奖励、事件、敌人意图、地图及三幕胜利流程没有本Mod内容。
- [ ] 本Mod新Run：角色名为“响木天音”，最大生命60，普通形态，堕落0、欲望0、魔装0。
- [ ] 初始牌组恰为4张打击、4张防御、1张变身；初始遗物为双魂圣杯。
- [ ] 开局从随机一个七宗罪任务和随机一个七美德任务中二选一；不能跳过；读档后不重复弹出。

## 2. 百科、奖励和文本

- [ ] 百科正式奖励牌数量：中立36、堕落52、圣洁43；名称、描述、类型、稀有度、费用、欲望费用与升级预览无裸键。
- [ ] 六张圣言可在百科/生成界面识别，但不进入普通奖励；事件/任务选择牌、状态牌、诅咒牌不进入普通奖励。
- [ ] 三路线普通战卡牌奖励持续非空，固定种子重复进入相同节点时路线与候选结果可重放。
- [ ] 不出现暗影撕裂、压制、贪得无厌、五张性技、拘束回避、战技复读、绳缚的心得或其他MVP跳过牌。
- [ ] 卡牌描述使用原版富文本风格；关键词不重复；动态伤害/格挡/抽牌/能量数值能解析且升级差值正确。

## 3. 核心资源与战斗生命周期

- [ ] 堕落限制在-5～5；奖励概率和圣洁/堕落封印在下一场战斗开始时按当前区间更新。
- [ ] 欲望跨战斗与保存读取保持；费用支付、免费化和X欲望行为正确；欲望不足时不可手动打出。
- [ ] 欲望达到10后回落到3并获得一回合“无法打出手牌”；回合结束后恢复。
- [ ] 变身获得3魔装；每段未格挡伤害逐层消耗保护；战斗结束清理战斗态但保留Run资源。
- [ ] 透支在魔装足够时直接支付，不足时弹出确认；拒绝不打牌，同意后魔装降至0且牌正常结算。
- [ ] 火堆批量移除封印牌免费且不占火堆行动；取消时不移除。
- [ ] 战斗中保存退出并继续至少两次，不黑屏；手牌、牌堆、欲望、魔装、Power与路线遗物的回合内状态合理恢复。

## 4. MVP卡牌机制组

- [ ] 中立：天平、基础牌强化、意图判断、燃烧、破碎、抽牌/费用、延迟结算、冰晶、附魔与路线桥接各测试至少1张及其升级版。
- [ ] 堕落：欲望获取/消费、状态/诅咒利用、生命替代、燃烧、自身减益、消耗输入/输出、力量/破碎、临时附魔各测试至少1张及其升级版。
- [ ] 圣洁：低欲望限制、降欲望、防御/冰雾、净化、自身与敌方减益、增益、断罪、圣言、大牌组、临时附魔、变身/额外回合各测试至少1张及其升级版。
- [ ] 融汇只生成三个本角色路线候选；选中牌本回合能量费用与欲望费用均为0，不显示Bug占位文本。
- [ ] 万咒之噬只从其他角色可生成的消耗牌中取样；选中牌本回合两种费用均为0。
- [ ] 污名先选“断罪/虚弱”，再从自己和可命中敌人中选一个角色；不能误用旧单目标流程。
- [ ] 光之审判在单敌人/多敌人、低于7层、正好触发阈值及万劫不复存在时均不重复审判或崩溃。

## 5. 临时附魔、断罪、净化和圣言

- [ ] 已有永久附魔的牌拒绝临时附魔；合法牌在战斗副本获得效果，牌组原实例不变化，战斗结束后不保留。
- [ ] 临时附魔牌在复制、变化、移动牌堆和保存读取后遵循原版附魔规则；灵魂联结、充能、铁壁、咒印传染各测试一次。
- [ ] 理外锻成只展示适用于当前合法手牌的3个候选，选定附魔后只能选择合法目标。
- [ ] 断罪叠层、7层审判、清除及万劫不复保留正确；净化获取、消费和减少自身负面效果正确。
- [ ] 六种圣言分别显示独立Power与剩余回合；生成、变化、升级、附魔、触发及持续时间均正确。

## 6. 遗物与事件

- [ ] 双魂圣杯：-3～3战后治疗5；≥4战后加5最大生命；≤-4治疗5并额外提供1次卡牌奖励。
- [ ] 双向棱镜：基础双路线各+20个百分点；中立区奖励可重掷；偏向区对应路线再+20个百分点。
- [ ] 枯木树枝：每当自己的牌被消耗，生成1张本角色随机牌到手牌；虚无消耗也触发且不递归崩溃。
- [ ] 15个原版事件指定选项只在原效果完整成功后改变±1堕落；取消选牌或异常中断不改变；同名后续按钮不重复。
- [ ] 5个门槛事件同时显示锁定/解锁选项，阈值、奖励、删牌/复制/永久附魔与心神宁静完全符合DesignDoc。
- [ ] 原版角色进入上述事件时没有新增选项、堕落/欲望变化或事件遗物奖励。

## 7. 十四路线任务与四阶段遗物

使用`ms_route set <Quest>`和`ms_route state`逐条验证；自然触发至少选一条暗路线和一条光路线，其余可用调试命令缩短流程。

- [ ] 七宗罪任务：Pride精英3、Greed持有300金币、Lust欲望≥5结束战斗3、Envy移除2牌、Gluttony用3药水、Wrath三回合内胜利4、Sloth火堆休息2。
- [ ] 七美德任务：Humility升级2张初始牌、Generosity跳过1宝箱、Chastity欲望≤2结束战斗3、Benevolence加5牌、Temperance跳过2卡牌奖励、Patience普通战5、Diligence火堆锻造3。
- [ ] 完成任务只结算一次：暗路线+1堕落、光路线-1堕落，获得对应“始源”遗物并标记碎片待售。
- [ ] 下一个商店的一个遗物位被碎片替换，价格固定199；未购买不会升级，购买后旧遗物被替换为“生长”。
- [ ] 生长阶段火堆出现免费献祭；暗路线只能献祭圣洁牌，光路线只能献祭堕落牌；不占火堆正常行动，完成后替换为“繁荣”。
- [ ] 第三层占位替换流程不会黑屏；Boss胜利后繁荣替换为圆满。堕落条件不满足时保持原版结束，满足时才追加第四层。
- [ ] 暗路线仅在堕落>-3时入场；光路线仅在堕落<3时入场；中立数值两类路线均可入场。
- [ ] 十四件遗物的始源/生长/繁荣效果逐一按DesignDoc测试；圆满延续繁荣状态且不重复拾取奖励。
- [ ] 特别回归：贪婪免费商店是否跨阶段保存；谦逊数值翻倍/牌面投影；慷慨放弃遗物删牌；仁爱繁荣奖励升级并只用原版附魔。

- [ ] `ms_act4 holy|neutral|corrupt`分别进入对应安全占位路线；命令结束后不会令之后所有Run无条件拥有第四层。
- [ ] 第四层地图、普通战、精英、事件、Boss占位能够进入和结束；正式敌人与Boss内容未伪装为已完成设计。
- [ ] 在任务进行中、始源、生长、繁荣、圆满及第四层地图分别保存读取；`ms_route state`字段、遗物阶段和章节入口保持一致。
- [ ] 完成普通战、精英、Boss、事件、商店、火堆与完整三幕Run；无未处理异常、持续错误日志或黑屏。
- [ ] 全项通过后将`PLAN_FRAMEWORK.md`和`DESIGN_TRACEABILITY.md`从`IMPLEMENTED/PENDING`更新为`VERIFIED`，并记录本次运行时基线。
