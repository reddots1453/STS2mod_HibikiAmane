# UI 与图标正式素材接入（2026-09-16）

## 版本边界

- 开发前快照：`maiden-pre-ui-icon-integration-20260916`（`125d9f1c4647fdfe6245aa10794c8084892cc211`）。
- 需求来源：用户要求将图片素材中的堕落条等 UI、图标接入并部署观察效果。
- 本轮只接入已有正式素材，不为缺少正式素材的新 Power 或“撕裂衣服”等机制擅自指定图标。

## 运行时变更

- 顶栏堕落值由程序绘制的色块改为 `-5..+5` 十一档完整天平纹理，继续保留逐刻度悬停说明。
- 左侧欲望计量条由程序绘制的十格色块改为 `0..10` 十一档完整纹理；超过 10 时保持满槽外观、数字显示真实值；战斗中不主动隐藏。
- 战斗费用旁的 RitsuLib 欲望次级资源 UI 改用粉色爱心小图和大图，不再使用原版辉星。
- 诱惑度 UI 改用正式诱惑图标，并与左侧欲望条保持间距。
- 圣洁、堕落路线卡牌通过 RitsuLib `ICardOverlayContributor` 显示 V3 衣装翼饰；中立路线不显示。
- 65 个已登记可见 Power 通过 RitsuLib 外部纹理提供器接入 64×64 状态栏图和 256×256 详情图；内部隐藏 Power 与没有正式素材的新 Power 继续使用原有回退。
- 拘束、侵犯、欲望攻击三种自定义意图使用正式图标；没有正式素材的“撕裂衣服”和衣物危险意图继续使用原版回退。
- 响木天音顶栏角色图标、轮廓图以及本 Mod 卡牌普通能量费用图标接入正式素材。
- 新增统一的松散 PNG 运行时加载缓存，兼容 Debug 松散资源与打包资源，避免依赖 Godot 导入数据库。

## 资产与验证

- 运行时只复制审阅后的成品：11 张堕落天平、11 张欲望条、5 张核心图标、2 张路线翼饰以及两套各 68 张 Power/机制图标。
- `scripts/ValidateVisualAssets.ps1` 对源素材和运行时副本逐文件校验 SHA-256，并验证关键代码接线。
- 验证命令：`dotnet build -c Debug --no-restore -p:DeployMod=false -p:ValidateMod=true`。
- 游戏内仍需手测顶栏宽度、手牌遮挡、卡牌放大、意图重绘与各种 UI 缩放下的布局；这些参数允许在验收截图后微调。
