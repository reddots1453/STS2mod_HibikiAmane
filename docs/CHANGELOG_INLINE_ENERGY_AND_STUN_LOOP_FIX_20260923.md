# 2026-09-23 — 文本能量图标与侵犯后击晕循环修复

## 用户可见修复

- 响木天音卡牌、附魔、遗物与状态描述中的能量图标改用本角色的魔法能量素材，不再显示铁甲战士的红色能量图标。
- 化石追踪者等敌人在执行侵犯意图、随后解除拘束时，不再因重复安排 `STUNNED` 而永久停留在击晕意图。

## 根因

- 卡框费用图标已有独立贴图补丁，但文本仍调用原版 `energyIcons()`；三个路线卡池的能量前缀仍为 `ironclad`，因此原版格式化器生成了战士图标。
- 侵犯结算会在当前动作后插入一次击晕；拘束解除路径可能再次请求击晕。第二次请求用同一个 `STUNNED` ID 覆盖状态机登记，并把新状态的后继指向旧的同名状态，最终解析为自身，形成自循环。

## 实现

- 新增独立的 `maidenEnergyIcons()` SmartFormat 格式化器，只供本模组本地化使用；图标从 `magic_energy_cost_icon_128.png` 准备为运行时资源，并以 `32x32` 富文本尺寸显示。
- 将本模组中文本地化中的能量格式统一迁移到新格式化器，不改动原版及其他模组的全局 `energyIcons()` 行为。
- `ForceStun` 在当前动作已经是击晕、或后继已经安排击晕时直接合并请求，禁止建立 `STUNNED -> STUNNED` 链。
- 新增调试自检和结构契约，覆盖当前击晕、对象后继击晕及仅状态 ID 后继击晕三种重复路径。
