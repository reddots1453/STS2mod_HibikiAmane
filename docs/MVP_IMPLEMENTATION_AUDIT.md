## 4. 第四层调试入口

- `ms_route state`：显示任务、进度、阶段、碎片、献祭和入场条件。
- `ms_route set <Quest>`：重置并指定十四任务之一；任务名使用`Pride/Greed/Lust/Envy/Gluttony/Wrath/Sloth/Humility/Generosity/Chastity/Benevolence/Temperance/Patience/Diligence`。
- `ms_route complete`：完成当前任务并获得始源遗物。
- `ms_route advance`：将现有路线遗物推进一个阶段，用于绕过商店或火堆进行局部测试。
- `ms_act4 <holy|neutral|corrupt>`：强制添加并进入安全占位第四层，只用于调试；不会永久打开无条件第四层。
- `ms_dump`：输出堕落、欲望、封印、路线进度和章节数量。

## 5. 尚需运行时确认的高风险边界

- Harmony事件包装必须在原版异步效果完整成功后结算，取消选牌不应改变堕落。
- 商店私有库存替换与购买完成事件依赖当前游戏版本实现。
- 路线遗物通过“移除旧实例、获得新实例”成长，贪婪的免费商店剩余状态必须跨阶段继承。
- 谦逊使用通用数值翻倍实现；牌面只含伤害/格挡的严格投影仍需在游戏中确认视觉和行为。
- 慷慨通过跳过遗物奖励触发删牌，需确认奖励界面的交互可理解且不重复。
- 条件追加第四层发生在第三层Boss胜利后，必须确认奖励页与章节切换均不黑屏。

以上项目已全部列入统一手测清单；失败时以日志、种子、步骤和`ms_dump`输出为回修证据。
