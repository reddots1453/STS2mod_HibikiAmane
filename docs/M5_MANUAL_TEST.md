# M5 统一手动测试清单

## 测试前准备

- 必须完全退出并重启游戏。M5新增角色、遗物、RunSavedData和Harmony补丁，不能只依赖热加载。
- 确认启用`MaidenSuccubus`与`STS2-RitsuLib 0.4.64`。
- 当前商店返金是未定稿调试配置，默认25金币；它不是正式平衡数值。
- 任意阶段可执行`ms_m5_state`检查开局档案、堕落值、侵犯诅咒数量、返金配置及已触发恩赐的幕。

## A. 启动与注册

- [ ] 角色选择界面同时出现“圣女与魅魔”“圣女”“魅魔”，名称和描述正常，没有本地化键原文。
- [ ] 百科全书中出现“光明恩赐（占位）”和“黑暗恩赐（占位）”，标题、描述正常。
- [ ] 启动日志没有`Harmony failed`、重复模型ID、本地化缺失或未处理异常。
- [ ] 原版角色的开局、商店和Boss奖励流程没有新增本Mod入口。

## B. 三种开局

分别创建新Run并立刻执行`ms_m5_state`：

- [ ] “圣女与魅魔”：`profile=Normal`且`corruption=0`。
- [ ] “圣女”：`profile=HolyMaiden`且`corruption=-3`。
- [ ] “魅魔”：`profile=Succubus`且`corruption=3`。
- [ ] 三者初始生命、金币、10张初始牌、初始欲望值完全一致。
- [ ] 三者都获得当前唯一已实现初始遗物“双魂圣杯”；没有重复遗物或空遗物槽。
- [ ] 三者的主题色可区分；角色模型仍共用占位资源，这是当前预期。
- [ ] 保存并读取后，初始堕落不会被再次叠加或重置。

## C. 商店特殊移除

在本Mod Run中执行：

1. `ms_add_invasion_curse sourced TEST_INVADER`
2. `ms_add_invasion_curse plain`
3. `ms_m5_state`
4. 记录当前金币及普通删牌价格，进入商店。

- [ ] 普通删牌入口附近出现“净除侵入诅咒”按钮，显示合格数量1和返金25。
- [ ] 点击后选择器中只能选择带来源的“精液”；空来源的同名诅咒不在候选中。
- [ ] 确认后带来源诅咒从永久牌组消失，金币增加25。
- [ ] 普通删牌入口仍可使用，价格和本局普通删牌次数没有变化。
- [ ] 牌组仍保留空来源“精液”，特殊按钮自动消失。
- [ ] 离开并重新进入商店时，空来源同名诅咒不会使按钮重现。

取消路径：

1. 再执行`ms_add_invasion_curse sourced CANCEL_TEST`。
2. 使用`ms_shop_curse 40`，在选择器中取消。

- [ ] 取消后诅咒、金币和普通删牌次数均不变。
- [ ] 再运行命令并确认移除，金币增加40；`ms_m5_state`显示`refund=40`。

## D. Boss恩赐独立页

先用调试命令快速检查页面：

1. 设置堕落为0。
2. 执行`ms_blessing offer`。

- [ ] 出现独立奖励页，光明与黑暗两个遗物作为互斥选项显示。
- [ ] 两者名称、图标和描述均可见，不显示本地化键。
- [ ] 选择光明后只获得光明占位遗物，堕落从0变为-1。

重新载入测试存档或新开Run，再执行`ms_blessing offer`：

- [ ] 选择黑暗后只获得黑暗占位遗物，堕落从0变为1。
- [ ] 跳过奖励页不会获得遗物，也不会改变堕落。
- [ ] 空恩赐池只产生清晰的占位回退警告，不会卡住奖励流程。

## E. 自然Boss流程与先古奖励共存

完成第一幕Boss：

- [ ] 原版Boss奖励页首先正常出现，卡牌、金币、遗物等均可正常领取或跳过。
- [ ] 若该Boss流程包含先古奖励，先古奖励可以正常完成，没有被女神恩赐替换。
- [ ] 原奖励流程结束后，额外出现一次女神恩赐页。
- [ ] 选择任一恩赐后能正常进入下一幕。
- [ ] `ms_m5_state`显示`blessingActs=[0]`；同一幕重进或读档不会再次自然弹出恩赐。
- [ ] 第二幕Boss后再次出现恩赐，状态扩展为`blessingActs=[0,1]`。

## F. 火堆与前置里程碑回归

- [ ] 欲望4时不显示“自慰”，欲望5时显示；执行后欲望变为3并结束火堆行动。
- [ ] 存在封印牌时可移除全部封印，且之后仍可选择休息或升级。
- [ ] 商店、Boss奖励与开局改动没有让堕落条/欲望条出现在原版角色中。
- [ ] M0-M4的卡牌奖励、临时附魔、控制、侵犯和欲望机制没有明显回归。
