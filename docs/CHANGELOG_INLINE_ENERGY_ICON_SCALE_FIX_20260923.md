# 卡牌内嵌能量图标尺寸修正（2026-09-23）

## 问题

本 Mod 的卡牌描述使用自定义魔法能量图标。大图预览会整体缩放卡牌富文本，原先显式指定的 `32x32` 尺寸也随之放大，导致图标明显高于文字行并挤压句尾。

## 修改

- 将 `MaidenEnergyIconsFormatter` 输出的富文本图片尺寸由 `32x32` 调整为 `16x16`。
- 保留既有魔法能量素材、重复图标规则与数值语义，仅修正显示尺寸。
- 更新结构契约，固定自定义能量图标必须使用 `16x16`，防止回退。
