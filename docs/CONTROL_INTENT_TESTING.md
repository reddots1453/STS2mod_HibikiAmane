# 拘束意图自动测试

## 目标与边界

本工具以`DesignDoc.md`的`SYS-CTL-001/002`及`SYS-DES-002B`为预期，专门验证“怪物执行拘束意图→施加拘束Power→原卡实例临时投影为挣脱→支付费用并精确减少挣脱值→解除或换源→安排恢复意图”的完整运行时链。

它不修改或测试尚未定稿的初始卡“变奏”设计，也不把“没有闪退”或“卡能打出”视为通过。每个场景都记录预期值和实际值。

## 运行方法

测试只存在于Debug构建。由玩家启动游戏，使用响木天音进入一场可以放弃的单人战斗，然后按：

```text
Ctrl+F10
```

普通`F10`运行全部222张注册卡牌测试，`Shift+F10`运行68张第二轮新增/变更卡牌测试；`Ctrl+F10`只运行9个拘束场景。也可以使用控制台：

```text
ms_test_control confirm
```

`confirm`是强制破坏性确认令牌。测试会清空战斗牌堆和Power、移除遗物、重建怪物状态机、生成大量夹具卡和临时多尼斯异鸟，因此只能在专用测试跑局执行，结束后应放弃该跑局。

## 自动断言

九个场景分别验证：

1. 拘束意图的稳定ID、格挡值、挣脱值和类型；格挡恰好相等时消耗对应格挡且不施加拘束。
2. 格挡少1时不消耗格挡、不造成生命伤害并施加精确拘束值；在手牌、抽牌堆和弃牌堆共60张以上夹具上压力测试投影与重复getter读取。
3. 欲望达到8时无视充足格挡，且不消耗这些格挡。
4. 攻击、技能、能力三类拘束只投影对应类型；随身技能和随身能力始终豁免。
5. 投影保留同一张升级卡实例；隐藏但不销毁保留、`Glam`附魔和`Bound`苦难；真实支付2费后原效果不结算、拘束精确减少2、牌进入弃牌堆，解除后全部原状态恢复。
6. 0费挣脱支付0费并减少0点拘束，原卡效果仍被抑制。
7. 多来源优先选择剩余挣脱值最低者；同值选择战场左侧来源；一次高额挣脱的溢出不转移。
8. 拘束来源死亡后移除该来源Power，并把卡牌重新绑定至仍存活来源；全部来源死亡后恢复。
9. 使用权威怪物目录强制多尼斯异鸟真实拘束意图，执行`MonsterModel.PerformMove`，以2费和1费两张攻击牌完成挣脱，并核对原攻击无伤害及`MAIDENSUCCUBUS_RECOVERY`恢复意图。

每个场景最长等待30秒。日志在真实怪物行动、投影压力读取、卡牌打出和来源死亡前后写入`CHECKPOINT`；若进程因栈溢出等不可捕获错误退出，最后一个检查点用于定位中断阶段。

## 输出

完整报告写入已加载模组程序集旁：

```text
control-intent-test-results/control-intents-YYYYMMDD-HHMMSS.json
control-intent-test-results/latest.json
```

正常完成的报告具有非默认`FinishedAt`，并列出9个场景、每条断言、耗时、最后检查点和异常堆栈。只有`9 passed, 0 failed`才表示自动部分通过；卡面锁链视觉、鼠标悬停排版和真实保存退出/重进仍需人工验收。
