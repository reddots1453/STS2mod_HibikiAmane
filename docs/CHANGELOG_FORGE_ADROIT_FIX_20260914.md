# 锻成・伶俐附魔类型修复（2026-09-14）

## 问题

“锻成・伶俐”错误使用了原版 `Nimble` 附魔。`Nimble` 只增加卡牌原有的格挡数值，且只能用于本身会获得格挡的卡牌；它不是商店遗物“木札”施加的“伶俐”。

## 原版依据

原版 `Kifuda` 明确使用 `Adroit`，固定层数为3。`Adroit.OnPlay` 在被附魔牌打出时独立给予3点格挡，且通过额外卡牌文本显示效果。

## 修改

- 悬停预览改为原版 `Adroit(3)`。
- 选牌合法性改用 `Adroit.CanEnchant`，不再限制为本身获得格挡的牌。
- 临时附魔改为 `CombatEnchantmentCmd.ApplyVanilla<Adroit>(selected, 3)`。
- 卡面改为原版附魔句式并换行：“为1张牌附魔：伶俐。”；“附魔”使用机制金色，“伶俐”使用附魔紫色。
- 自动测试锁定附魔类型、层数，并实际打出被附魔防御牌，验证其总共获得5+3点格挡。
- 结构验证禁止该卡重新使用 `Nimble`。
