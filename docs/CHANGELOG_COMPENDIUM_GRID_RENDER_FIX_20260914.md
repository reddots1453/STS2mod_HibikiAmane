# 百科全书路线卡网格渲染修复（2026-09-14）

## 用户可见问题

- 响木天音筛选项右下角统计为 161 张牌，但卡牌网格为空白。
- 两张初始基础牌“少女打击”和“少女防御”未计入总览；按设计应显示 161 张三路线牌与 2 张初始基础牌，共 163 张。

## 运行时证据

最新游戏日志显示，路线筛选已经正确产出 161 张牌；随后 `NCardGrid.InitGrid` 为 canonical 卡牌生成描述时，在“暗元素”的 `AddExtraArgsToDescription` 中读取 `CardModel.Owner`，触发 `CanonicalModelException`。异步网格初始化因此中断，形成“数量存在但网格为空”的画面。

此外，`NCardLibraryGrid` 会先按 `ShouldShowInCardLibrary` 构造 `_allCards`，之后才执行路线筛选。初始基础牌继承的共享衍生牌基类原本固定传入 `false`，所以它们在补丁运行前就已被排除。

## 修改

- “变身”和“暗元素”的动态描述仅在可变卡牌实例上读取 `Owner`；canonical 百科全书模型使用安全的默认分支，不再中断网格渲染。
- `MSGeneratedCard` 的百科全书可见性改成默认关闭、可由具体卡牌显式开启。
- 仅“少女打击”和“少女防御”显式开启百科全书可见性；圣言及其他衍生牌继续保持隐藏。
- 结构验证器新增以下回归门：
  - 衍生牌默认隐藏及参数透传；
  - 两张初始基础牌显式可见；
  - 两张动态描述牌必须先检查 `IsMutable` 再访问 `Owner`。
