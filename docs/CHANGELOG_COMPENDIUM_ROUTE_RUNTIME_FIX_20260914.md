# 百科大全路线卡池运行时修复（2026-09-14）

## 用户可见问题

- 百科大全的响木天音筛选器仍只显示 44 张中立路线牌。

## 日志证据与根因

- 最新 `godot.log` 显示模组初始化在 `FrameworkSelfTests.Run` 中异常退出：堕落值 `+2` 的圣洁路线概率仍按旧断言期待 `0.10`，而第二轮 DesignDoc 与实现均为 `0.08`。
- 异常发生在响木天音 Harmony 补丁安装之前。因此全部 204 张牌仍由 RitsuLib 注册，但 `CardLibraryRoutePoolPatch` 没有加载，百科筛选器退回角色基础 `MSNeutralCardPool`，只显示 44 张牌。
- 同一日志还记录“泡澡”的 `NextEnergy` 被声明为普通 `DynamicVar`，无法交给原版 `energyIcons` 格式器渲染。

## 修复

- 将路线概率自检更新为 DesignDoc 第二轮表：幅度 2 为 `20% / 8% / 72%`，幅度 4 为 `45% / 0% / 55%`，幅度 5 为 `65% / 0% / 35%`（正负方向镜像）。
- 运行时自检失败现在会完整记录错误，但不再阻断后续模组初始化和 Harmony 补丁安装，避免 Debug 部署形成“内容已注册、行为补丁未加载”的半初始化状态。
- “泡澡”的 `NextEnergy` 改为具名 `EnergyVar`，与原版 `energyIcons` 格式器契约一致。
- 结构验证器新增上述三项回归门。

## 百科大全预期

- 响木天音角色筛选器应显示 163 张牌：44 张中立路线牌、62 张堕落路线牌、55 张圣洁路线牌，以及共享衍生池中显式允许展示的 2 张初始基础牌。
- 其余共享衍生牌、圣言、状态牌与侵犯诅咒仍不得进入百科大全。
