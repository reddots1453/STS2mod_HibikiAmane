# 卡牌能量图标自动字号修正（2026-09-23）

## 问题

将内嵌能量图标写成 `[img=16x16]` 后，图标实际显示尺寸缩小，但游戏的 `MegaLabelHelper` 在估算卡牌正文尺寸时会忽略图片标签中的尺寸参数，仍按底图的原始 `128x128` 尺寸计算。因此，含能量图标的卡牌正文会被错误缩小。

## 修正

- 从正式素材复制真正的 `32x32` 魔法能量文本图标到运行时资源目录。
- `MaidenEnergyIconsFormatter` 改用该 `32x32` 资源。
- 富文本改为原版一致的 `[img]资源路径[/img]`，不再显式指定尺寸。
- 自动字号测量与实际渲染现在都会读取同一个 `32x32` 原始尺寸。
- 增加结构契约，禁止自定义能量格式化器重新使用 `[img=...]`。
