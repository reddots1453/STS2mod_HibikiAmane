# 变奏基础牌卡面格式修复（2026-09-14）

## 范围

本轮按用户要求只修复“变身”和“黑暗元素”卡面直接显示 SmartFormat 模板源码的问题，不包含其他卡牌语义、悬停栏或文本格式整改。

## 根因

原版 `ShowIfUpgradedFormatter` 的 `show` 格式器只接受 `IfUpgradedVar`。这两张牌把普通布尔参数 `IsCorrupt` 写成了 `{IsCorrupt:show:真分支|假分支}`，格式器拒绝处理后整段描述回退为模板源码，因此连伤害、格挡变量也没有展开。

## 修改

- “变身”改用原版布尔分支格式 `{IsCorrupt:真分支|假分支}`。
- “黑暗元素”改用同一原版布尔分支格式。
- 保留 DesignDoc 规定的语序、换行、路线阈值与颜色标注。
- 本地化格式验证新增防回归规则：`show` 只能由 `IfUpgraded` 使用，普通布尔参数必须使用标准布尔分支语法。
