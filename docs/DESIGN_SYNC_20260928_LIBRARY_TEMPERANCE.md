## 已确认与实施语义

- Q21用户已确认：留在手牌时持续生效。不是打出书库时赋予；Q22“打出赋予后持续多久”不适用。
- 邻接以当前拥有者实际Hand牌序为准，只有直接左右邻牌，无环绕；抽牌、弃牌、消耗、移动和书库离手时重算。
- 原生OnPlayWrapper先将目标移入Play，再计算结果牌堆和重放次数；仅在BeforeCardPlayed处理已太晚。需在Wrapper入口捕获Hand相邻贡献，用实例级、可嵌套的作用域保留当前打出，异步任务结束／失败／取消时清理。只保留书库贡献，不能清除卡牌自身消耗、其他重放或附魔。
- 预览查询不得修改原牌的永久Keywords或附魔，不能写入Run牌组/克隆存档。无书库、非手牌、非本角色、其他拥有者应不受影响。
- 颜色框为UI效果，不将卡图重绘或打包新原作素材；跟随原生NCard缩放/位置，更新并在离手/节点销毁时清理。不得覆盖原生可打出、选牌或其他Mod高亮。
- 节制之戒复用旧书库的抽牌/弃牌/消耗三堆选择规则；空堆或不足数量按实际可用牌，无重复抽样返回牌；不私自增加跳过选项。临时禁抽用原生本回合状态，不改变节制之环持续禁抽。
- 保留旧Power保存身份以免旧战斗存档无法载入；展示改为新环。旧节制遗物加载不补发奖励；只有实际阶段拾取发放。普通升级和保存恢复不能重新触发一次性奖励。

## 实现入口及测试迁移

1. `Iteration1CorruptCards.InsatiableGreed`：新技能及持续邻接服务，保留RegisterDustyTomeCard；额外效果显示走原生关键词/重放查询，作用域只负责当前打出。
2. `YarusLibraryPower`与`LibraryPileChoice`：抽出可复用三堆自动出牌命令，十张循环供环使用，3/4张供戒使用；保留玩家/战斗/选项身份重验和原随机流。
3. `TemperanceRouteRelic`及`FourthRouteTrialRules`：替换旧BeforeCombatStart与TemperanceMaximum，拾取幂等；新增衍生牌适当卡池，先古不进普通奖励。
4. 全部zhs卡牌、Power、遗物/选择提示、内容清单、引用/素材回退、调试登记和卡牌审计须一起同步；不能只改变卡牌效果而留旧标题/耗能/描述。
5. 旧`DesignSyncLibraryContract`的三堆数量/RNG/取消/不合法/状态移除等200断言迁到环，书库新增独立邻接用例，不复用旧文本来虚报覆盖。全文清单、225硬编码计数、原先古审计例外随新增两牌同步，不跳过旧失败。
6. `ms_test_combat_virtues`节制旧测试替换为拾取永久牌组、各阶段数量、重入/读档不重发、不再开战选牌；耐心原测试保持。

## 验收矩阵

- 书库基础/升级元数据、原生虚无、实际卡面全文、尘封魔典准确给新技能。
- 无邻牌/左边界/右边界/两侧、手牌重排、两书库夹同一张牌同时获得消耗和重放；离手后撤销、返回后重建。
- 原有消耗/华彩/其他重放不丢失；当前打出的邻牌真正额外执行一次及真正进入消耗堆；书库自身普通打出／回合末虚无无残留。
- 手牌外预览、永久牌组、保存克隆、其他角色和拥有者隔离；实际节点红绿框大小/缩放/清理仍须游戏验证。
- 节制2/2/3试炼，旧1次进度不提前领奖；戒/戒/环各阶段拾取只发一次且加入永久牌组，不在开战重复。
- 戒基础/升级3/4、当回合禁抽和下回合恢复；环十张与持续禁抽；三牌堆空/不足/超过数量、生成返回/死目标/中途结束/取消/异常/RNG隔离。
- Debug/Release无部署、所有静态/纯规则/编码/内容/视觉门及全卡审计重新运行；第70批指纹漂移记录保留，新的统一报告必须前后一致。
