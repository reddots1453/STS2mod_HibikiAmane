# 原作CG与音频演出游戏内手测清单

状态：代码与静态资源门已实现；以下项目在实际游戏中通过前不得标记`VERIFIED`。

## 设置与角色隔离

- [ ] 主菜单模组设置“响木天音 → 过场与音频”中分别开启CG与成人音频，重启后保持选择；两个开关互不影响，默认新安装均关闭。
- [ ] 普通音量与成人音量分别设为0%/100%，触发变身及拘束时各自独立生效；重启后数值保持。
- [ ] 使用其他角色进入战斗、火堆和房间切换：不创建本Mod过场节点，不播放本Mod音频。
- [ ] 成人CG关闭：拘束、侵犯、自慰均不出现遮罩或等待，规则照常结算。
- [ ] 成人音频关闭：不加载或播放拘束、侵犯、撕衣、呼吸、自慰类音频；普通变身、魔法和欲望提示可正常播放。
- [ ] 分别调整普通音效与成人演出音量提供器，确认两类音量互不影响。

## 拘束与侵犯

- [ ] 拘束成功`Applied`：按怪物档案显示正确单张CG及chain/hold音效；附加效果随后继续结算。
- [ ] 拘束被格挡、目标无效或结算失败：不显示CG，不播放拘束音。
- [ ] 侵犯成功：诅咒写入后播放start、对应CG、finish，随后继续附加效果并进入恢复/晕眩意图。
- [ ] 侵犯失败：不显示CG，不播放侵犯音，不强制晕眩。
- [ ] 触手、异形、人形群体、寄生、史莱姆、魔法器具、默认弱怪各验证一例；语义明显不匹配时记录怪物ID以调整独立档案。

## 欲望与循环音

- [ ] 欲望7→8只播放一次`desire_high`并启动一个心跳循环。
- [ ] 欲望8→9不重复高值提示，也不叠加第二个心跳。
- [ ] 欲望9→10只在高潮平复即时或延迟结算登记后播放`desire_full`。
- [ ] 读档/战斗开始恢复到8或10不重播普通跨阈值提示；8及以上战斗状态可恢复单例心跳。
- [ ] 欲望降到8以下、战斗结束、换房、保存退出、返回主菜单时心跳停止且无残留节点。
- [ ] 同一怪物一次多段欲望攻击最多播放一次touch/tentacle音效；每次行动的breath在动作结束后停止。
- [ ] 撕裂衣服音效只在实际执行撕衣效果时播放，不因意图出现提前播放。

## 火堆自慰

- [ ] 欲望不足5时选项不可成功，不播放CG或音频。
- [ ] 欲望不少于5并确认后，按start→peak→afterglow播放；peak播放climax并淡出循环音。
- [ ] 任意画面用鼠标、确认键和取消键跳过：欲望仍降至3，首次堕落值仍+1，火堆行动仍正常消耗。
- [ ] 全屏过场期间点击手牌区、结束回合等底层UI不产生输入穿透。

## 生命周期与多人

- [ ] 过场播放中结束战斗、换房、保存退出或返回主菜单：遮罩和全部音频可靠清理，无黑屏或持续音。
- [ ] 连续触发两个过场后立即切场景：已播放和排队的过场都被取消，不在新场景补播。
- [ ] 多人中只有被结算的本地响木天音显示过场/播放音频；远端玩家不重复显示，规则命令只执行一次。
