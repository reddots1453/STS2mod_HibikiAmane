# 原版怪物色情攻击分配表

> 需求ID：`MON-ERO-CATALOG-001`
>
> 成熟度：`OPEN`
>
> 规则权威：色情攻击、拘束、侵犯和魔装概率以[`../DesignDoc.md`](../DesignDoc.md)为准；本文只负责原版怪物的适配分配。

## 1. 文档用途

本表为原版怪物分配允许使用的色情攻击类型，使怪物保留原有外形、动作和战斗风格，而不是统一套用同一种色情意图。

分配代码：

- `A`（欲望攻击）：独立意图；可以只增加1点或更多欲望，也可以造成较低的攻击伤害并增加欲望；
- `B`（拘束）：可以主动施加拘束；
- `I`（侵犯）：玩家已被拘束时，可以使用侵犯意图；
- `S`（意志坚定）：没有色情攻击，跳过色情攻击判定，并免疫将其意图改为色情攻击的效果；
- `—`：不允许该类型。

“允许类型”只定义候选集合，不定义三类意图之间的具体权重。`I`在玩家未被拘束时始终不是合法候选。每个怪物ID必须至少具有`A/B/I`之一，或者单独具有`S`；`S`不能与`A/B/I`并存。

## 2. 匹配原则

1. 具有法术、孢子、毒液、凝视、诱导、气味或其他匹配表现的怪物可以获得`A`。欲望攻击是独立意图，不得直接继承原意图的全部效果；其数值应设计为纯增加欲望，或较低伤害加欲望。
2. 具有藤蔓、丝线、黏液、触肢、巨口、夹钳、长尾、绳索、机械抓取或压制动作的怪物可以获得`B`。
3. 具有生物性、类人生物性、寄生性、吞噬性或明确侵入表现的怪物可以获得`I`；纯粹武器、炮台、雕像和一般构装体默认不获得`I`。
4. 不适合色情表现的纯机械、静物、门、蛋、肢体分段或附属物使用`S`。意志坚定显示在怪物状态栏中，并使该对象不参与色情攻击判定。
5. Boss可以拥有更完整的候选集合，但具体数值、诅咒和重复次数仍需单独设计，不能因Boss身份自动提高概率。

## 7. 意图效果规格

下列规格是逐怪物意图表的一部分。表中“名称＋规格编号”共同构成完整意图；实现和本地化不得只显示规格编号。

### 7.1 欲望攻击

| 规格 | 效果 |
|---|---|
| `A1` | 欲望增加1。 |
| `A2` | 造成4点伤害，欲望增加1。 |
| `A3` | 造成6点伤害，欲望增加1。 |
| `A4` | 欲望增加2。 |
| `A5` | 造成8点伤害，欲望增加2。 |

欲望攻击是独立意图。上述伤害会被力量、虚弱、易伤、格挡和魔装正常影响；纯增加欲望的`A1/A4`不视为攻击，也不会触发魔装防护。

### 7.2 拘束

| 规格 | 效果 |
|---|---|
| `BA1` / `BS1` / `BP1` | 需要8点格挡阻止；失败则分别拘束攻击牌/技能牌/能力牌，挣脱值2。 |
| `BA2` / `BS2` / `BP2` | 需要12点格挡阻止；失败则分别拘束攻击牌/技能牌/能力牌，挣脱值3。 |
| `BA3` / `BS3` / `BP3` | 需要16点格挡阻止；失败则分别拘束攻击牌/技能牌/能力牌，挣脱值5。 |

拘束意图本身不造成生命伤害。格挡与拘束的其他结算沿用DesignDoc的`SYS-CTL-001`。

### 7.3 侵犯

| 规格 | 效果 |
|---|---|
| `I1` | 造成5点伤害，将1张“淫纹·轻微”加入牌组。 |
| `I2` | 造成6点伤害，将1张“衣装透明”加入牌组。 |
| `I3` | 造成6点伤害，将1张“痴情”加入牌组。 |
| `I4` | 造成6点伤害，将1张“口球”加入牌组。 |
| `I5` | 造成8点伤害，将1张“淫纹·扩散”加入牌组。 |
| `I6` | 造成10点伤害，将1张“淫纹·扩散”加入牌组。 |

所有侵犯规格只有在玩家已被拘束时合法。每个怪物每场战斗至多成功执行一次侵犯；成功后进入晕眩意图，且本场战斗不再使用拘束或侵犯。当前没有Boss例外。

## 8. 逐怪物色情意图

`S`条目没有色情意图，其状态栏显示“意志坚定”。同一行列出多个ID时，这些原版变体共用名称与效果。

本节条目继承第3～6节同名对象行中的怪物ID。被拆分设计的组合行按以下关系对应，避免实现歧义：`KIN_FOLLOWER`=同族随从，`KIN_PRIEST`=同族祭司；`BOWLBUG_NECTAR/ROCK/SILK`=蜜液/岩壳/丝型盛碗虫；`CRUSHER/ROCKET`=帝皇蟹夹钳/火箭；`FLAIL_KNIGHT/MAGI_KNIGHT/SPECTRAL_KNIGHT`=链枷/法师/幽灵骑士；`QUEEN/TORCH_HEAD_AMALGAM`=女王/火炬头聚合体；`THE_LOST/THE_FORGOTTEN`=失落/遗忘之物；`CALCIFIED_CULTIST/DAMP_CULTIST`=钙化/潮湿邪教徒；`GREMLIN_MERC/SNEAKY_GREMLIN/FAT_GREMLIN`=地精佣兵/潜行地精/肥胖地精。

### 8.1 密林

- 红宝石劫掠者（五种）：A「下流挑衅」`A2`；I「剥衣凌辱」`I2`。
