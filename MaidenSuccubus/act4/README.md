# Fourth Act asset boundary

This directory is the stable resource boundary for the Maiden & Succubus
Fourth Act. The M6 placeholder intentionally falls back to Glory assets so a
missing final map, background, music, or boss asset cannot corrupt a run.

Final content should be added under:

- `map/`
- `backgrounds/`
- `encounters/`
- `bosses/holy/`
- `bosses/neutral/`
- `bosses/corrupt/`
- `music/`

Do not change the registered Act or route ModelIds when replacing placeholders.
